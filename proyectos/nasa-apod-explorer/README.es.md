Aplicación web para explorar la Imagen Astronómica del Día de NASA.

## Resumen

Aplicación web para explorar la Imagen Astronómica del Día de NASA, buscar imágenes históricas por fecha y guardar favoritos en localStorage. Construido con HTML, CSS y JavaScript usando la NASA Open API.

## Implicaciones

Demuestra integración de APIs, diseño responsive y persistencia de datos del lado del cliente en una interfaz limpia y accesible.

## Desafíos

- Implementar consultas históricas por fecha
- Manejar límites de tasa de la API de NASA
- Mantener layouts responsive en móvil y desktop

## Resultados

Desplegado en GitHub Pages con colaboración en equipo. Features: búsqueda por fecha, gestión de favoritos y galerías responsive.

## Stack Tecnológico

- JavaScript
- Curl
