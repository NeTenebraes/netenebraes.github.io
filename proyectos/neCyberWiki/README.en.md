## Overview

neCyberWiki is a free, open-source educational resource that centralizes practical cybersecurity knowledge in one accessible location. Built with **Obsidian** for content creation and published via **Quartz** as a static site, it bridges the gap between personal note-taking and public knowledge sharing.

The wiki covers penetration testing methodologies, security tool references, cheatsheets, and foundational computer science concepts — all organized for quick lookup during security assessments.

## What's Inside

- **Pentesting Guides** — Step-by-step methodologies for common attack vectors
- **Cheatsheets** — Quick-reference cards for tools like Nmap, Burp Suite, and Metasploit
- **Tool References** — Detailed usage guides for security auditing tools
- **CS Fundamentals** — Networking, cryptography, and operating system concepts
- **Custom Configurations** — Obsidian templates and Quartz plugins for knowledge management
